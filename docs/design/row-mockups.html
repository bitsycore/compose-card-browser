The same four at true phone width — no board chrome

400px, only the row's own padding

The panels above add ~80px of board chrome the app does not have, which is the whole reason every line wrapped up there. At real width all four fit on one line — including the worst case, three languages and a full date. The right column drops the day anyway; it buys ~21px and reads better in a column, since the day of the month is never what is being compared.
